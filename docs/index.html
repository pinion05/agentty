Python REPL, Vim, Claude Code 등 모든 대화형 도구를 자유롭게 제어하세요.

npm i -g agentty-cli

왜 Agentty인가요?

🚀 Non-Blocking

입력을 기다리는 CLI 도구 때문에 에이전트가 멈추지 않습니다. 백그라운드 PTY 세션으로 완벽하게 분리됩니다.

💾 Stateful Sessions

attach 명령어로 언제든 작업 중이던 세션으로 돌아가세요. 문맥을 잃지 않고 작업을 이어갈 수 있습니다.

🤖 Meta-Agent Ready

에이전트가 또 다른 에이전트(Claude Code, Gemini CLI)를 고용하여 대화하며 협업하는 워크플로우를 만드세요.

어떻게 작동하나요?

agentty-session
$ agentty start --name py -- python3
Started session: py (pid: 12345)

$ agentty text "print('Hello Agent')"
$ agentty key Enter

$ agentty get
>>> print('Hello Agent')
Hello Agent
>>>

바로 시작하기

# 1. 세션 시작 (예: Python)
agentty start --name dev -- python3

# 2. 명령 전송 (텍스트 입력)
agentty text "import os"
agentty key Enter

# 3. 결과 확인 (스냅샷 조회)
agentty get

# 4. 세션 종료
agentty kill
